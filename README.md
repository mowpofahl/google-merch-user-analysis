# google-merch-user-analysis
Analyzing new vs. returning user behavior on the Google Merchandise Store using SQL and BigQuery — part of a larger Tableau dashboard and UX research case study.

This project investigates whether new and returning users on the Google Merchandise Store have meaningfully different behavioral patterns — and what that implies about who the product is optimized for. Using Google's publicly available GA4 obfuscated sample dataset in BigQuery, I wrote SQL queries to extract session-level behavioral and conversion data segmented by user type, then visualized findings in an interactive Tableau Public dashboard. The full analysis is presented as a UX research case study on my portfolio.


Tools: SQL · BigQuery · Tableau Public


Data: Google GA4 Obfuscated Sample Dataset · November 2020 – January 2021
